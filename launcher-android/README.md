# Lumora Home 🏠

Launcher (Startbildschirm) mit sechs Looks: **Apple**, **Android (Pixel)**, **One UI 9**, **Galaxy Klassik**, **Nothing**, **ColorOS**.

- Icon-Formen je Look (Squircle, Kreis, abgerundete Quadrate, monochrom)
- Uhr-Widgets je Look (iOS-Karte, Pixel-Datum, große One-UI-Uhr, gestapelte Galaxy-Uhr, Nothing-Punktuhr, dünne ColorOS-Uhr)
- Dock, Suchleiste, App-Übersicht mit Suche, Favoriten, Gesten
- Einstellungen: Look, Spalten, Icon-Größe, Namen, Uhr, Dock, Suche, monochrome Icons
