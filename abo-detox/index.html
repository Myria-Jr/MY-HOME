Mit YouTube verbinden

Füg einmalig deine Google OAuth Client-ID ein. Sie bleibt nur in diesem Browser gespeichert.

Woher krieg ich die Client-ID? (5 Min.)
  1. Google Cloud Console → neues Projekt anlegen.
  2. YouTube Data API v3 aktivieren.
  3. OAuth-Zustimmungsbildschirm: Typ „Extern“, Status „Testen“, und deine eigene Google-Adresse als Testnutzer eintragen.
  4. Anmeldedaten → OAuth-Client-ID → Typ „Webanwendung“. Bei „Autorisierte JavaScript-Quellen“ diese Adresse eintragen:
  5. Client-ID kopieren, hier einfügen, fertig. Beim Login warnt Google „App nicht verifiziert“ → „Weiter“ (ist ja deine eigene).
